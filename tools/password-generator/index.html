A Truly Random Password Generator

Weak, reused and predictable passwords are still the single biggest cause of account takeovers. This generator creates passwords using your browser's cryptographically secure random number generator — the same source used for security tokens and encryption keys — so every password is unpredictable and unique.

What makes a password strong

FactorWhy it matters
LengthEach extra character multiplies the number of possible combinations an attacker must try.
Character varietyMixing uppercase, lowercase, numbers and symbols increases the pool of possible characters per position.
RandomnessPredictable patterns — keyboard walks, dictionary words, dates — are guessed by attackers long before random combinations.
UniquenessA strong password reused across sites is only as safe as the weakest site that stores it.

Best practices for storing your new password

Use a password manager

Save generated passwords in a reputable password manager rather than memorising or writing them down.

Enable two-factor authentication

A strong password plus 2FA protects an account even if the password is somehow exposed.

Never reuse passwords

Generate a fresh one for every account so a breach on one site can't cascade to your others.

Password Generator FAQ

Is this password generator actually secure?

Yes. It uses the Web Crypto API (crypto.getRandomValues), the same cryptographically secure random source browsers use for security features, not Math.random(), which is predictable and unsuitable for passwords.

Are the passwords sent to a server or logged anywhere?

No. Every password is generated locally in your browser using JavaScript. Nothing is transmitted, stored, or visible to anyone but you.

What length password should I use?

12 characters is a reasonable minimum today; 16 or more is recommended for anything sensitive, such as an email account, password manager master password, or financial login.

Should I exclude ambiguous characters like 0, O, l and 1?

Only if you'll be typing the password by hand, such as reading it off a screen to enter on another device. If you're copying and pasting or storing it in a password manager, there's no benefit to excluding them.

Why does the strength meter say a password is weak even though it's long?

Strength considers both length and character variety. A long password using only lowercase letters is weaker than a shorter one mixing uppercase, numbers and symbols, because it draws from a smaller pool of possible characters per position.

Should I reuse a strong password across multiple sites?

No. Reusing any password — even a strong one — means a single data breach on one site can compromise every account using it. Generate a new one for each account and store them in a password manager.

Can I generate more than one password at a time?

Press 'Generate another' as many times as you like — each click produces a brand new independent password using the same settings.
