How to Compress a JPEG to an Exact File Size (KB)

Many upload forms cap images at a specific size — 100 KB, 200 KB, sometimes less. Guessing a quality percentage until it fits wastes time. Here's a faster way.

The problem with quality-slider-only compressors

A typical compressor asks you to pick a quality percentage and see what file size comes out. If a form requires an image under 100 KB, that usually means several rounds of trial and error — compress, check the size, adjust, repeat.

How to compress a JPEG to a target size

  1. Open JPEG Compressor.
  2. Upload your image.
  3. Switch to the "By target size (KB)" tab.
  4. Enter the limit you need, for example 100.
  5. Press "Find best quality for this size" — the tool searches for the highest quality that still fits.
  6. Download the result.

Where this is most useful

  • Job application portals with strict photo or document size limits.
  • Government and exam forms that cap ID photo or signature uploads.
  • Email attachments, to avoid bounced messages on slow connections.
  • Website forms with a hard maximum upload size.

Compress from the original, not a copy

JPEG compression is lossy, meaning some image detail is discarded permanently every time you save. Always start from your best-quality original rather than re-compressing a file that's already been compressed once, which stacks quality loss unnecessarily.

Quality slider mode still has its place

If you don't have a strict size requirement and just want the smallest reasonable file, the regular quality slider with a live before/after preview is usually the quicker option.
