## 2. Selection method

The category→guide map was derived from existing site evidence, not guessed:

1. Parse each of the 129 guide pages for its existing `related-block` cards.
2. Resolve each related tool URL to its tool-manifest category.
3. Rank guides per category by the number of existing related tools in that category.
4. Fill categories with no strong related-tool signal using title/URL topic matches limited to that category's subject matter.
5. Cap each category at three guides. Calculator retained only one guide because only one high-confidence match existed.

Evidence map: `C:\Users\ahmad\AppData\Local\Temp\opencode\ewt-t049-guide-map.json`.

## 3. Implementation

### 3.1 Shared renderer

`scripts/category-sections.mjs` was extended with:

- `CATEGORY_GUIDE_LINKS`: 10 category slugs and 28 guide slugs.

`scripts/build-indexes.mjs` now passes the already-loaded `posts` array into `renderCategoryPageBody()`. The same data drives the generated page and its anchor text, so a renamed guide updates the link label on the next build.
